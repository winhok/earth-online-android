# 地球 Online 1.5.0 · 天命契约与可恢复成长

Android 离线单人版，包名 `xyz.winhok.earthonline`，版本代码 2，最低 Android 8.0。APK 使用 1.0.0 的原签名，可直接覆盖升级；升级前仍建议先导出存档。AAB 是渠道提交格式，不是手机安装文件。

## 本次功能

带日期的一次性任务与 Boss 采用明确披露的时限契约：先查看奖励、逾期全额代价与主动弃约半额代价，再确认签订。旧日期任务不追溯处罚，逐项校准；日常和无日期任务不会变成历史负债。

延期会调整可获奖励，第三次进入重审；再次延期需要先解除旧约再重新承诺。到期离线核对只结算一次，每份契约独立记账，不按离线天数复利。完成、撤销、重做、迟到完成、偿债分配与豁免均有可追溯记录，不能靠重复点击或换叙事制造奖励。

新增当前有效经验、债务、历史最高等级、契约账本、结算核对和真实任务恢复路线。不可抗力仅选择原因类别，不采集病情或家庭细节；补偿保留原记录，不发放虚假完成奖励。

地球原生与修仙使用同一份底层事实，切换名称、境界、道果、配色与反馈，不改变任务原文、经验、债务或完成身份。手机突出一个下一步行动，支持右滑完成与非手势按钮、大字体、横竖切换、宽屏导航、深浅主题以及可关闭的声音／触觉／动态效果。

## 验证与数据

本 Release 由门禁工作流在领域、叙事、Debug／Release Lint、构建和 API 26／29／35／36 的模拟器验收成功后创建。附件包含原始仪器测试、真实屏幕截图、同一签名 APK 的覆盖升级与 SAF 存档测试，以及文件和证书摘要。具体用例数量以 `acceptance-summary.json` 为准，不把合并请求、代码存在或版本号当成测试通过。

Room 数据库 v1→v2→v3 使用显式迁移；导出协议为 v3，兼容读取有效 v1／v2 存档。备份为明文、上限 8 MiB。导入先校验和预览，再确认事务覆盖；删除数据会删除本机任务、契约、债务与记录。完整旧备份仍可恢复旧时间线，这是数据所有权，不承诺离线防作弊。
