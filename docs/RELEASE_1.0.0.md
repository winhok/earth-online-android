# 地球 Online 1.0.0

首个可独立安装的 Android 离线单人版。下载 `earth-online-1.0.0.apk` 安装；AAB 是应用商店投递格式，不能直接安装。

## 功能范围

主线目标、支线 / 日常 / Boss 任务，任务编辑、完成与撤销、暂停 / 暂缓 / 归档，等级与五项技能、成就、冒险日志、本地规则的下一步推荐、深浅色主题、可选每日提醒，以及带校验和覆盖确认的 JSON 存档。

无需账号、服务器或 API Key；没有广告、云同步或远程 AI。角色技能值只是应用内进度，不代表真实个人能力。备份为明文，存档大小上限 8 MiB，写入前执行保守容量保护。

## 发布门槛

发布工作流只有在领域测试、Debug / Release Lint、签名 APK / AAB 构建，以及 Android API 26、29、35、36 的仪器测试和同一签名 APK 黑盒操作全部成功后才创建此 Release。测试设备为 GitHub Actions 的 Android 模拟器，不冒充实体手机。

黑盒检查包括离线上线、创建任务、完成、撤销、强制停止重启、页面导航以及系统文件选择器的存档导出和覆盖恢复。附件提供 APK / AAB 校验和、签名证书、源代码提交和设备证据。

## 使用边界

这次是 GitHub 直接分发，不是 Google Play 或国内应用商店上架。尚未声称通过小米 / 华为等实体设备的后台保活、省电或通知准点验收；提醒是尽力调度，不保证准点。首次将其作为重要任务记录工具前请保留自己的备份。无云端恢复；卸载或清除数据前务必导出。
