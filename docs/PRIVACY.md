# 隐私说明 · 离线单人候选版

版本：1.0.0-rc.1。此说明描述当前源码行为，不是已经上线的服务合同。正式对外分发前，维护者需要确认发布主体、支持联系方式及目标渠道要求。

应用保存玩家名、自定义服务器名、存档时区、界面与提醒设置、任务、主线、完成记录和手记。数据保存在 Android 应用沙盒的 Room 数据库，不包含账号密码、定位轨迹或通讯录。首次创建角色取设备时区，但不获取 GPS 位置。

当前应用源码不请求 INTERNET 或定位权限，不接入广告、分析、远程崩溃收集、AI API、登录或云同步。WorkManager 等依赖可能在最终合并 Manifest 中声明调度所需的普通系统权限；正式发布前必须审核最终 Manifest，不能只看 app 清单。

通知为用户主动开启的可选能力。Android 需要时通过系统权限弹窗确认，拒绝权限不影响核心任务功能。通知仅展示可行动任务数量，不放任务标题或手记。系统省电、权限和厂商策略可能导致提醒延迟或缺失。

数据库没有另加应用层加密，依赖设备及系统的存储保护。应用配置禁用自动备份，并给出数据提取限制；OEM 的设备迁移/备份行为尚待真机验证，不作绝对保证。

导出时，应用通过 Android 系统文件选择器把明文 JSON 写到用户指定位置。文件可能被保存到本地、移动介质或用户选择的云文件提供商。云提供商的传输与保管由该提供商控制。导入在应用本地解析，应用自身不上传文件。摘要校验不是加密，不能使分享给他人的明文变得保密。

用户可在设置中删除本机全部存档。删除不会销毁之前导出的文件，后者需要用户在对应位置自行管理。卸载或清除应用数据可能永久删除未导出的本机存档。正式发版前需在目标设备与文件提供商上验证删除、备份和恢复流程。
