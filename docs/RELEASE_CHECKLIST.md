- [ ] 连续点击/多协程完成只产生一个有效奖励。

- [ ] 保存时区 23:59→00:00，每日只产生正确日期的一条完成记录。
- [ ] 跨午夜的撤销精确作用于原完成记录。
- [ ] 夏令时、旅行切时区、设备时钟前后跳、日常未开始/暂停/归档都经过检查。
- [ ] 过期不扣分；暂缓不改变截止日；归档保留历史；主线进度不被重复日常冲高。

## 存档、损坏与容量

- [ ] 本地文件和一个系统云文件提供商的 SAF 导出/导入实测成功。
- [ ] 中文、表情、换行、引号、长手记和多个主线存档往返无丢失。
- [ ] 损坏摘要、重复 ID、断裂外键、超长字段、非法奖励、未来版本、超过 8 MiB 均拒绝。
- [ ] 导入解析失败、事务中断、存储空间不足后原数据库保留。
- [ ] 导入覆盖前显示正确预览并确认；导入后提醒关闭。

- [ ] 在 1,000 / 10,000 条任务及长日志下测启动、内存、交互、备份大小和恢复时长。
