## 未来升级不得绕过

APK 包名保持 `xyz.winhok.earthonline`，使用交付的同一签名身份，versionCode 递增。不能重新运行首次 bootstrap 来更换签名密钥。数据库实体发生变化时，递增 Room 版本、添加迁移并保留 v1 schema。受测提交、发布文件、签名证书与测试中的 APK 摘要必须对应，禁止把旧成功报告用于新的运行时代码。
