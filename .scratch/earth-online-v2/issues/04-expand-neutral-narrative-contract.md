# 04: 扩展中立叙事契约

**What to build:** 在不改变现有界面的前提下，加入可扩展的叙事注册、类型化语义目录、结构化参数、能力矩阵和地球原生解释器，使应用第一次能够通过统一边界表达同一份领域事实。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 叙事体系拥有稳定 wire ID、结构版本、内容版本、支持语言、明暗方案、能力声明、继承声明和资源声明。
- [ ] 系统文案通过中立语义 key 与结构化参数生成，不执行最终字符串查找替换。
- [ ] 语义目录能够返回文案、图标角色、颜色角色和效果角色。
- [ ] 可选 Surface Provider 只能读取统一 UI 状态并调用稳定动作接口，不能直接访问 Room 或领域持久化。
- [ ] 目的地、动作、字段、状态、错误、通知、成就和事件拥有稳定语义 ID。
- [ ] 地球原生体系作为默认注册，并能在至少一个代表性现有流程中输出与当前行为一致的表现。
- [ ] 玩家名、服务器名、任务／主线标题、说明和手记作为不透明参数原样输出。
- [ ] 纯 Kotlin 表驱动测试证明解释前后领域对象完全相等。
- [ ] 测试证明包含“任务”“XP”等词的玩家原文不会被误替换。
- [ ] 新旧表达可以暂时并存，为后续 expand–contract 迁移保持构建绿色。
