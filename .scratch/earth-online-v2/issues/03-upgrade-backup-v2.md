# 03: 升级备份协议至 v2

**What to build:** 让用户能够完整导出、预览和恢复叙事选择、契约、代价、债务与恢复状态，同时继续安全导入 1.0 备份，不让显示偏好或未知体系阻塞核心数据恢复。

**Blocked by:** 02: 建立 Room v2 兼容外壳.

**Status:** ready-for-agent

- [ ] v2 备份完整包含叙事选择、体系展示偏好、契约、修订、代价、分配、豁免、返还、时钟边界和恢复状态。
- [ ] v1 备份可以升级导入，旧日期任务保持未签约并默认地球原生体系。
- [ ] 未知叙事体系 ID 被原样保留，显示安全回退地球原生，不阻塞其他有效数据。
- [ ] 导入预览明确显示任务、完成、契约、债务、恢复路线和叙事体系的变化数量。
- [ ] 完整快照恢复允许回到较旧时间线，不在快照外强行保留本机债务或偏好。
- [ ] 重复 ID、断裂关联、非法状态、 impossible allocation、损坏摘要、超限内容和未来协议版本全部在替换前拒绝。
- [ ] 编码前容量预算包含全部新增记录，导出不会生成自身无法重新导入的文件。
- [ ] 替换失败时原存档逐项保持，提醒设置继续遵守恢复后关闭的既有规则。
- [ ] 特殊字符、中文、emoji 和大规模记录能够无损往返。
