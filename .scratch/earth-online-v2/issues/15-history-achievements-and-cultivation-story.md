# 15: 完成历史、成就与修仙故事表达

**What to build:** 让同一份人生历史在修仙体系中形成完整而可信的境界、道果、劫痕和重修篇章，同时保持玩家原文、稳定 ID 和所有解锁条件不变。

**Blocked by:** 08: 实现原子体系切换与修仙外壳; 14: 交付失序／堕仙恢复路线.

**Status:** ready-for-agent

- [ ] Quest、Side Quest、Daily、Boss 和 Mainline 分别映射为历练、支线历练、日课、渡劫和仙途。
- [ ] XP、Level、Achievement 映射为修为、境界、道果，底层数值与成就 ID 不变。
- [ ] 契约、改期、弃约、代价、债务、失序和恢复映射为天命契约、改命、解契、劫罚、劫债、道心失序和重修仙途。
- [ ] 五项技能映射为悟性、根骨、造化、因缘和道心，技能计算不变。
- [ ] 境界按已确认等级区间从炼体展示到真仙，并始终同时显示 `Lv.N`。
- [ ] 堕仙只作为失序恢复覆盖状态，不成为永久等级或数据库身份。
- [ ] 成就名称、描述、图标和庆祝由当前体系解释，切换不重新解锁或发奖励。
- [ ] 未来结构化事件随当前体系动态重译，玩家标题快照与手记保持原文。
- [ ] 旧版无法拆分的日志正文原样展示，只重译已知事件类型。
- [ ] 修仙故事章节只由中立事实解锁，不保存第二份修为、任务或角色进度。
- [ ] 体系升级可以改善历史表达，但不重写任何权威记录。
