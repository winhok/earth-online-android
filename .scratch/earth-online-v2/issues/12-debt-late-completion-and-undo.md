# 12: 交付债务、迟到完成与撤销重做

**What to build:** 让逾期真正影响当前境界，同时让玩家通过继续完成现实行动逐笔修复；迟到完成、撤销和重做都不能制造或消灭修为。

**Blocked by:** 11: 交付逾期核对与批量天劫结算.

**Status:** ready-for-agent

- [ ] 历史有效完成奖励与当前有效修为分开显示，当前修为扣除代价后允许掉级但不低于 Lv.1。
- [ ] 超出当前修为的负额保留为债务，不能因余额为零而消失。
- [ ] 债务归零前，新获得的全局 XP 全部优先偿债；技能 XP 和完成成就正常增长。
- [ ] 完成优先偿还与自身契约关联的债，剩余部分按最早债务优先，并持久化分配。
- [ ] 逾期后完成获得当前衰减奖励，原逾期事件不撤销；未改期任务因此回到净零而非继续升级。
- [ ] 撤销用于偿债的完成时，奖励和对应分配一起回滚，债务恢复。
- [ ] 截止后撤销原本按时的完成前，必须明确警告将产生的完整逾期代价。
- [ ] 重做使用原完成奖励与技能快照，并按重做时的债务重新分配。
- [ ] 历史最高境界保留；单纯逾期不扣任何技能 XP。
- [ ] 当前修为、债务、分配和撤销日志可以逐笔解释且跨进程重开一致。
- [ ] 右滑完成与可见完成按钮调用同一个幂等命令，不因动画或重复手势多结算。
