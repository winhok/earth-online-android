# 14: 交付失序／堕仙恢复路线

**What to build:** 当玩家持续失约或承担足以掉落整级的债务时，提供一条由真实任务组成、明确可以走完的恢复路线，让堕仙成为阶段而不是永久判决。

**Blocked by:** 12: 交付债务、迟到完成与撤销重做; 13: 交付不可抗力补偿.

**Status:** ready-for-agent

- [ ] 债务大于零时显示中立失序状态，修仙体系解释为道心失序。
- [ ] 最近 30 个契约时区日内三次完整逾期会开启恢复路线。
- [ ] 债务达到当前等级完整一级所需 XP 时也会开启恢复路线。
- [ ] 主动弃约、改期和不可抗力不计入三次完整逾期。
- [ ] 玩家从现有真实任务中选择预计奖励足以覆盖债务的恢复节点。
- [ ] 同时最多突出三项，完成后动态补位，不生成虚假任务或特殊奖励。
- [ ] 恢复任务继续使用普通奖励、契约和偿债规则，不能通过先违约再恢复套利。
- [ ] 债务归零或全部有效豁免后立即记录重返正轨并关闭本轮路线。
- [ ] 旧违约历史保留，但不会立即重开已完成路线；必须发生新的完整逾期。
- [ ] 地球原生和修仙共享同一恢复状态，只改变失序／堕仙与恢复／重修的表达。
- [ ] 无候选任务时提供创建或调整真实任务的入口，不自动替玩家编造行动。
