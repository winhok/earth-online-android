# 06: 迁移平台与历史文案

**What to build:** 让角色、日志、设置、错误、通知和无障碍反馈进入统一叙事体系，并建立旧日志原文与未来结构化事件之间的明确兼容边界。

**Blocked by:** 04: 扩展中立叙事契约.

**Status:** ready-for-agent

- [ ] 角色页的等级、技能、连续行动和成就名称通过中立 ID 解释。
- [ ] 日志的事件类型使用当前体系动态重译，旧版事件正文和玩家手记保持原样。
- [ ] 新系统事件保存中立事件 key 与结构化参数，不把完整渲染句子作为权威事实。
- [ ] 设置、隐私、存档预览、删除确认和版本说明中的应用自有文案进入解释器。
- [ ] ViewModel 消息和业务错误按中立类型解释，并继续保留真实数值与动作结果。
- [ ] 通知标题、正文和可见渠道名称可由体系解释，内部渠道和工作标识保持稳定。
- [ ] 通知仍不显示私人任务标题，已投递通知不会因切换而重复发布。
- [ ] Android 权限框和文件选择器保持系统原文，不被伪装或复制。
- [ ] 屏幕阅读器能够获得完整的状态、动作和后果，不依赖图标、颜色或动画。
