# 10: 交付暂缓、改期、弃约与重新签约

**What to build:** 让玩家能够诚实调整承诺并清楚承担相应代价：暂缓一天真的顺延一天，反复改期削弱奖励，主动退出比完整逾期轻，但所有历史都可解释。

**Blocked by:** 09: 交付旧任务校准与签约闭环.

**Status:** ready-for-agent

- [ ] 有效契约的“暂缓一天”在同一事务将截止日与可见日各顺延一个契约时区自然日。
- [ ] 无日期任务只隐藏一天；日常只跳过当天，不改变开始日期或创建债务。
- [ ] 每次延后让本轮可得奖励减少原始奖励的 20%，最低保持 40%，并记录契约修订。
- [ ] 提前截止日期不降低奖励，但保留旧日期和新日期审计。
- [ ] 第三次延后进入待重审，第四次必须半额弃约旧契约并重新签约。
- [ ] 清除日期、暂停、归档或改变锁定类型／技能／奖励规则按原始奖励的一半向上取整结算。
- [ ] 标题、说明、优先级和预计时间可以编辑并留痕，不改变锁定风险。
- [ ] 已完成契约后普通编辑、暂停或归档不产生新代价。
- [ ] 已逾期任务先结算，再通过“重新约定明天”创建新契约，旧责任永久保留。
- [ ] 同一个一次性任务即使多次签约，最终仍只有一个完成奖励槽位。
- [ ] 左滑只露出暂缓和改期；弃约、归档等高风险动作必须进入明确确认。
