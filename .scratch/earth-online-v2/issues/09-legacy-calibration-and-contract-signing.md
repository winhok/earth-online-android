# 09: 交付旧任务校准与签约闭环

**What to build:** 让老用户安全决定哪些旧日期继续成为承诺，并让所有新日期任务在保存前看见对称奖励与代价，从签约到按时完成形成第一条完整可演示链路。

**Blocked by:** 08: 实现原子体系切换与修仙外壳.

**Status:** ready-for-agent

- [ ] 升级后的旧日期任务逐项显示未签约状态，不追溯处罚、不阻塞其他使用。
- [ ] 校准提供签约、改期和无代价移除旧日期，禁止危险的批量全部同意。
- [ ] 未签约旧任务仍可按旧规则完成；首次编辑日期时必须进入签约披露。
- [ ] 新签约截止日期最早为契约时区的今天，过去日期明确拒绝而非自动修改。
- [ ] 选择今天时说明只剩当天剩余时间，但领域边界仍为完整自然日。
- [ ] 保存前同时展示原始奖励、逾期全额代价和主动弃约半额代价。
- [ ] 修仙体系以天命契约呈现，同时保留真实日期、修为数值和明确后果。
- [ ] 签约锁定类型、技能、时区、原始奖励和罚则快照。
- [ ] 按时完成获得当前约定奖励，契约正常终结，完成和审计同事务落地。
- [ ] 重复点击或并发完成仍只产生一个完成奖励和一个契约结果。
