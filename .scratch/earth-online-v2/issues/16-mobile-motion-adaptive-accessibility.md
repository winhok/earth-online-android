# 16: 完成手机交互、演出和自适应体验

**What to build:** 将已选“宗门战令”世界完整落实到手机和基础大屏，让完成、逾期、掉级和恢复都有明确触感与视觉节奏，同时保持 Android 原生、可访问和可关闭。

**Blocked by:** 09: 交付旧任务校准与签约闭环; 10: 交付暂缓、改期、弃约与重新签约; 11: 交付逾期核对与批量天劫结算; 12: 交付债务、迟到完成与撤销重做; 13: 交付不可抗力补偿; 14: 交付失序／堕仙恢复路线; 15: 完成历史、成就与修仙故事表达.

**Status:** ready-for-agent

- [ ] 实现批准 Comp 的黑漆玉简、稀缺金箔、朱砂劫痕、地球星轨和大胆数值层级，不照抄示例日期或虚构指标。
- [ ] 右滑完成具有明确阈值、一次触觉和玉简归轨反馈；左滑只露出暂缓与改期。
- [ ] 所有手势保留可见按钮和无障碍动作，高风险操作不能靠全滑直接执行。
- [ ] 完成、境界突破、逾期、掉级、偿债和恢复拥有不同但一致的短促演出，不满屏持续发光或粒子。
- [ ] 声音默认关闭，触觉默认开启并服从系统设置，提供全局效果控制。
- [ ] 系统减少动态效果时，所有演出替换为静态状态变化或短交叉淡入，不丢信息。
- [ ] 所有触控目标至少 48dp，并保留系统返回、预测返回、系统栏和 IME Insets。
- [ ] 手机采用单列和下半屏主动作；大于等于既有宽屏断点时使用 Navigation Rail 与双栏内容。
- [ ] 修仙浅色方案使用矿物浅玉与深墨，不退化为泛黄羊皮纸；深色保持文字和警告对比。
- [ ] 大字体、屏幕阅读器、横屏、分屏、草稿恢复和进程重建均保持核心动作可达。
- [ ] 体系切换期间任何动画、触觉或声音都不能重复领域命令。
