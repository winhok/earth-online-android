# 08: 实现原子体系切换与修仙外壳

**What to build:** 让玩家在设置中随时、完整地切换地球原生与修仙体验，保留正在进行的操作，并看到“地球 Online”母品牌下真正不同的修仙世界，而不是换词半成品。

**Blocked by:** 01: 锁定 Comp-first 方向契约; 02: 建立 Room v2 兼容外壳; 03: 升级备份协议至 v2; 07: 收口地球原生兼容层.

**Status:** ready-for-agent

- [ ] 设置中使用同一条真实任务预览两套体系，点选后先验证再原子持久化。
- [ ] 地球原生是旧数据和新用户默认，选择不阻塞创建角色。
- [ ] 修仙体系完整注册简体中文、浅色、深色、资源、能力和继承声明。
- [ ] 选择与跟随系统／浅色／深色相互独立，所有组合均可恢复。
- [ ] 切换保留当前目的地、筛选、滚动锚点、选中任务和未保存编辑草稿。
- [ ] 状态驱动弹窗立即重绘；一次性动画取消后只显示稳定结果，不重复领域命令。
- [ ] 目标体系失败时旧体系与 UI 状态保持完整；启动发现无效体系时整套回退地球原生并保留请求 ID。
- [ ] 产品名、Launcher 身份和地球轮廓保持母品牌，修仙可以改变应用内材质、轨道和演出。
- [ ] 修仙四个核心目的地均可访问，系统返回、深链和通知导航使用稳定语义 ID。
- [ ] 切换本身不改变任何任务、完成、XP、技能、契约、债务或成就事实。
