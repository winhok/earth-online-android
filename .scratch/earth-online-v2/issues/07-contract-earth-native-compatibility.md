# 07: 收口地球原生兼容层

**What to build:** 完成叙事文案 expand–contract 的收口，让地球原生体系成为唯一完整的现有体验表达来源，并用自动检查阻止未来页面绕过叙事契约。

**Blocked by:** 05: 迁移核心操作界面文案; 06: 迁移平台与历史文案.

**Status:** ready-for-agent

- [ ] 所有应用自有领域文案、状态、错误、通知和无障碍表达都有明确语义 key 或主动共享声明。
- [ ] 删除已经没有调用者的旧系统文案入口和重复格式化路径。
- [ ] 不删除或改写任何玩家原文、旧日志原文、稳定枚举值和备份 wire 值。
- [ ] 地球原生能力矩阵覆盖全部一级目的地、动作和重要状态。
- [ ] 完整性测试在缺失 key、资源、语言、明暗方案或能力声明时明确失败。
- [ ] 主动继承共享组件可以通过清单验证，运行时意外漏项不能静默混搭。
- [ ] 纯 Kotlin 主测试入口覆盖地球原生全部语义 key 和代表性结构化参数。
- [ ] 应用在地球原生体系下通过现有页面与主题验收，不产生可见回归。
