# 05: 迁移核心操作界面文案

**What to build:** 让应用外壳、指挥台、任务列表、编辑器和公共组件全部通过中立叙事契约呈现，同时保持地球原生用户看到的功能、信息和操作结果不变。

**Blocked by:** 04: 扩展中立叙事契约.

**Status:** ready-for-agent

- [ ] 顶栏、四个一级目的地、FAB、加载、存档错误和通用空状态使用稳定语义 key。
- [ ] 指挥台的等级、Next Quest、推荐理由、任务数量和待重审表达通过解释器生成。
- [ ] 任务列表的筛选、主线入口、状态和空结果表达通过解释器生成。
- [ ] 任务、主线和手记编辑器的字段、辅助说明、保存、取消和放弃确认通过解释器生成。
- [ ] 任务卡的完成、奖励、优先级、难度、日期、逾期和重审状态使用结构化参数，不拼接不可重译的最终句子。
- [ ] 公共卡片、统计块、全屏编辑框架和无障碍动作名称使用同一契约。
- [ ] 玩家输入和历史标题快照逐字保持，不进入翻译或替换流程。
- [ ] 地球原生截图与语义测试证明迁移没有删除功能或改变业务命令。
- [ ] 当前系统返回、草稿恢复、IME Insets 和忙碌状态保持不变。
