# 13: 交付不可抗力补偿

**What to build:** 让疾病、照护、事故等现实事件能够诚实地修正契约责任，不删除已经发生的历史、不要求私人说明，也不让豁免变成完成奖励。

**Blocked by:** 12: 交付债务、迟到完成与撤销重做.

**Status:** ready-for-agent

- [ ] 玩家可以在逾期结算前或之后选择不可抗力结果。
- [ ] UI 同时使用体系叙事和明确现实含义；修仙显示“尘世变故／不可抗力”。
- [ ] 只保存非隐私原因类别，不要求自由文本、证明材料或健康详情。
- [ ] 事前豁免不奖励、不处罚，并以终局结果关闭契约。
- [ ] 事后豁免不删除原处罚，而是追加不可变补偿事件。
- [ ] 未偿债务按对应金额免除；已经偿还的部分等额返还当前修为。
- [ ] 补偿不增加技能 XP、不授予任务完成或成就。
- [ ] 多次提交、并发操作和进程重开不会重复返还。
- [ ] 不可抗力不计入 30 日完整违约次数。
- [ ] 屏幕阅读器能够理解豁免不会被视为完成，也不会泄露私人任务信息。
